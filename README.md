# 👨‍💻 Adam Salhi | Portfolio Website

This is my fully responsive **personal portfolio website**. It serves as a modern digital CV to showcase my skills, professional projects, and work experience to recruiters and collaborators.

## ✨ Key Features
- 🎨 **Modern & Dark Theme UI** - Clean, professional design with smooth animations.
- 📱 **100% Responsive** - Works perfectly on Desktop, Tablet, and Mobile devices.
- 📄 **One-Click PDF Download** - Instantly download my full CV in PDF format.
- 🔗 **Direct Contact** - Integrated WhatsApp, Email, and GitHub links.

## 🛠️ Built With
- **HTML5** - Semantic and accessible structure.
- **CSS3** - Flexbox, Grid, Custom Properties, and Animations.
- **JavaScript** - Intersection Observer API for scroll animations.
- **FontAwesome** - Professional icon set.
- **Google Fonts** - Typography (Inter).

## 📂 Project Structure
- `index.html` - Main HTML structure.
- `style.css` - All styling and responsive design.
- `script.js` - JavaScript logic.
- `cv.pdf` - My downloadable Curriculum Vitae.
- `photo cv.png` - My profile picture.
